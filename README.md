# 업무자료 AI 도우미 (DocAid)

학교 업무자료(매뉴얼·지침·공문 PDF)를 등록해 두고, 물으면 **등록한 자료에서 근거를
찾아 답하고 그 근거가 된 파일과 쪽을 함께 보여 주는** Windows 프로그램입니다.
같은 근거로 가정통신문·문자 초안도 씁니다.

> 자료도, AI 실행도 **이 컴퓨터 안에서만** 이루어집니다.
> 업무자료·검색 색인·질문·답변을 외부 서버로 보내지 않습니다.

**v0.1.0 — PDF 만 지원합니다.** 한글(HWP/HWPX) 파일은 한글에서 PDF 로 저장한 뒤
등록하세요. HWPX 직접 지원은 다음 버전(v0.2)의 첫 항목입니다.

---

## 무엇을 해 주나요

| 기능 | 설명 | AI 필요 |
|---|---|---|
| **자료집 · PDF 등록** | 업무자료를 주제별로 묶어 등록합니다 | 아니오 |
| **원문 보기** | 등록한 PDF 를 그 자리에서 열고, 찾은 자리를 형광펜으로 표시합니다 | 아니오 |
| **자료 검색 (낱말)** | 낱말로 찾습니다. 조사가 달라도, 표 안의 값도 찾습니다 | 아니오 |
| **자료 검색 (혼합)** | 뜻이 비슷한 문장까지 찾습니다 (낱말 + 의미 검색) | 검색 모델 |
| **규정 해석** | "경조사비는 1인당 얼마까지?" 처럼 물으면 근거를 찾아 답합니다 | 답변 모델 |
| **문서 작성** | 같은 근거로 가정통신문·문자 초안을 씁니다 | 답변 모델 |
| **작업 기록** | 무엇을 물었고 그때 어떤 근거로 답했는지 남습니다 (기본 30일, ★ 중요 표시는 보존) | 아니오 |

### 지어내지 않습니다

이 프로그램의 첫째 원칙은 "답을 잘 쓰는 것" 이 아니라 **등록 자료에 없는 것을 지어내지
않는 것**입니다.

- 답변마다 **어느 파일 몇 쪽**에서 나왔는지 보여 주고, 누르면 그 PDF 의 그 자리가 형광펜으로 칠해집니다.
- 답에 든 금액·날짜·횟수·비율은 **인용한 근거 안에 그 값이 있는지** 확인합니다. 없으면 표시합니다.
- 근거를 찾지 못하면 답하지 않고 **"등록된 자료에서는 이 질문에 답할 수 있는 근거를 충분히 찾지 못했습니다"** 라고 말합니다. 관련이 있는 근거는 그래도 보여 줍니다.
- 화면 어디에도 "검증 완료" 라고 쓰지 않습니다. 확인한 것만 확인했다고 씁니다.

## AI 없이도 씁니다

AI 를 설치하지 않아도 프로그램은 실행되고 **자료집 · PDF 등록 · 원문 보기 · 낱말 검색 ·
작업 기록**은 그대로 됩니다. AI 는 프로그램 안 **[AI 기능 설치]** 에서 안내에 따라
따로 설치합니다.

### AI 기능을 쓰려면

1. **로컬 AI 실행환경 [Ollama](https://ollama.com)** — 프로그램이 내려받기 쪽을 열어 줍니다. 설치는 한 번입니다.
2. **검색 모델** — `bge-m3` (1.2GB). 혼합 검색에 씁니다.
3. **답변 모델** — PC 메모리에 따라 프로그램이 권합니다.

| PC 메모리 | 권장 답변 모델 | 내려받기 | 이 PC(CPU)에서 답 하나에 |
|---|---|---|---|
| 8GB | 가벼운 답변 모델 `gemma3:4b` | 3.3GB | 약 1분 남짓 |
| 16GB 이상 | 기본 답변 모델 `qwen3:8b` | 5.2GB | 약 2~3분 |

이 권장은 실제 업무자료 3종·67문항으로 재어 정한 것입니다(개발 문서 참고). 모델을
받을 때만 인터넷이 필요하고, 받은 뒤에는 인터넷 없이 됩니다. 색인(의미 검색 준비)은
CPU 에서 청크 하나에 0.8초쯤 — 300쪽 자료면 5~10분이며, 멈춰도 다음에 이어서 합니다.

> GPU 가 없는 보통 학교 PC 기준입니다. 답을 기다리는 동안 화면에 "이 PC 에서는 보통
> N분 걸립니다" 를 **이전 실행 시간**으로 보여 줍니다.

## 설치

[Releases](https://github.com/lohemal/document-ai-assistant/releases) 에서
`DocAid_0.1.0_x64-setup.exe` 를 내려받아 실행하세요. 관리자 권한이 필요 없고, 현재
사용자 계정에만 설치됩니다.

> Windows 가 **"PC 를 보호했습니다"** 창을 띄우면 **추가 정보 → 실행** 을 누르세요.
> 코드 서명 인증서가 없는 프로그램은 모두 이렇게 나옵니다. 알려진 한계입니다 —
> 내려받은 파일이 온전한지는 릴리스의 `SHA256SUMS.txt` 로 확인할 수 있습니다.

## 자료는 어디에 있나요

```
%APPDATA%\kr.school.docaid\
  data.db        검색 색인 · 작업 기록 (물었던 것 · 답 · 당시 근거)
  files\         등록한 PDF 사본
  backups\       자료구조를 올릴 때와 [지금 백업] 을 누를 때 만드는 data.db 사본

%USERPROFILE%\.ollama\models\    AI 모델 (Ollama 가 관리 — 업무자료가 들어가지 않습니다)
```

설정 화면 **[자료 폴더 열기]** 로 바로 열 수 있습니다. 프로그램을 업데이트해도,
지웠다 다시 깔아도 이 폴더는 그대로 남습니다.

> ⚠ **이 폴더는 업무자료 그 자체입니다.** 등록한 PDF 원문, 검색 색인, 물었던 것과
> 답이 모두 여기 있습니다. 개인정보가 담긴 자료를 등록했다면 이 폴더와 백업 파일에도
> 같은 주의가 필요합니다. 이 프로그램은 자료를 외부로 보내지 않지만, **폴더 자체를
> 암호화하지는 않습니다.** (암호화는 v0.2 항목)

## 백업 · 다른 PC 로 옮기기 · 복구

**백업** — 설정의 **[지금 백업]** 이 `data.db` 를 `backups\` 에 복사합니다(앱이 켜진
채로도 온전합니다). 등록한 PDF 사본(`files\`)은 크기가 커서 여기 들어가지 않으니
**폴더를 통째로 복사**하세요.

**옮기기·복구 (손으로)**
1. 프로그램을 끕니다.
2. `%APPDATA%\kr.school.docaid\` 폴더 전체를 복사합니다 (`data.db` + `files\`).
3. 새 PC 에 프로그램을 깔고 한 번 실행한 뒤 끕니다.
4. 복사한 폴더를 같은 자리에 덮어씁니다. 다시 실행하면 자료집·색인·기록이 그대로입니다.
   AI 모델은 새 PC 에서 [AI 기능 설치] 로 다시 받습니다.

복원 화면은 v0.2 에 넣을 예정입니다. 자료구조가 바뀐 버전으로 올라갈 때는 프로그램이
먼저 `backups\pre-migration-…db` 를 만들어 두므로, 문제가 생기면 그 파일을 `data.db`
자리에 되돌려 놓고 **그 버전의 프로그램**으로 열면 됩니다.

## 업데이트

설정의 **[업데이트 확인]** 을 누를 때만 GitHub 에 새 버전이 있는지 확인합니다 —
프로그램을 켠다고 나가지 않고, 업무자료는 어떤 경우에도 보내지 않습니다. 새 버전은
**서명이 맞을 때만** 설치됩니다. 인터넷이 없거나 아직 배포된 버전이 없으면 그렇다고
말하고 지금 버전을 그대로 씁니다.

옛 버전 프로그램으로 새 버전이 만든 자료를 열면 **"프로그램을 최신 버전으로 업데이트한
뒤 다시 열어 주세요"** 라고 말하고 자료를 건드리지 않습니다.

## 알려진 한계 (v0.1.0)

- **PDF 만** 등록할 수 있습니다. 스캔본(글자 없는 PDF)은 등록되지만 검색되지 않습니다 (OCR 은 v0.2).
- **답변 모델은 지어낼 수 있습니다.** 프로그램은 인용·숫자·주장을 근거와 대조해 막지만, 근거를 제대로 옮겨 적고도 **물음과 다른 이야기**를 답으로 내놓는 경우는 다 잡지 못합니다(실측: 자료에 없는 물음 15개 가운데 gemma3:4b 4개, qwen3:8b 2개가 통과). **답 옆의 근거 원문을 꼭 함께 보세요.** 화면이 그렇게 만들어져 있습니다.
- 숫자 확인은 **그 값이 인용 근거 안에 있는지**만 봅니다. 값이 그 자리에 맞게 쓰였는지(A 금액을 B 금액으로 바꿔 쓴 것)는 잡지 못합니다.
- 문서 작성은 자료에 없는 학교명·날짜·연락처를 `[학교명]` 처럼 비워 둡니다. 채워서 보내세요. 근거에 없는 문장·숫자는 본문에 표시됩니다.
- 코드 서명 인증서가 없어 설치 때 SmartScreen 경고가 납니다.
- 자료 폴더를 암호화하지 않습니다.
- CPU 만 있는 PC 에서 답 하나에 1~3분 걸립니다.
