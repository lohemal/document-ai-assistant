DocAid v0.1.0 — 업무자료 AI 도우미 첫 배포

학교 업무자료(PDF)를 등록해 두고, 그 자료 안에서 근거를 찾아 답하는 Windows 프로그램입니다. 첫 정식 배포판입니다.

## 할 수 있는 것

- **PDF 자료집 등록·관리** — 자료집을 만들고 PDF 를 등록합니다. 쪽 단위로 글자를 뽑아 둡니다.
- **AI 없이도 되는 낱말 검색과 원문 확인** — 낱말로 찾고, 결과를 누르면 원문 PDF 가 그 쪽에서 열리고 해당 자리에 형광펜이 칠해집니다.
- **로컬 의미 검색** — 검색 모델(bge-m3)을 받아 두면 낱말이 달라도 뜻이 가까운 자리를 함께 찾습니다(낱말 검색과 섞어 순위를 매깁니다).
- **등록 자료에 근거한 규정 해석** — 물음을 넣으면 자료집에서 근거를 먼저 찾고, 찾은 근거만으로 답합니다. 근거가 없으면 없다고 말합니다.
- **가정통신문·문자 초안 작성** — 같은 방식으로 근거를 찾아 초안을 씁니다. 학교명 같은 빈칸은 `[학교명]` 자리로 남기고, 확인하지 못한 문장은 표시합니다.
- **답변의 근거·쪽·원문 확인** — 답 옆에 인용한 근거의 문서 이름·쪽·원문을 늘 함께 보여 주고, 원문 PDF 를 바로 열 수 있습니다. 답에 든 숫자가 인용 근거에 없으면 경고합니다.
- **작업 기록과 중요 표시** — 물음·답·그때의 근거를 기록으로 남기고, 중요한 것은 ★ 표시로 보존기간과 무관하게 남깁니다.
- **Ollama 기반 로컬 AI** — 검색 모델과 답변 모델은 이 PC 의 Ollama 에서 돕니다. 모델은 설치 뒤 프로그램 안 [AI 기능 설치] 에서 따로 받습니다. 8GB PC 는 gemma3:4b, 16GB 이상은 qwen3:8b 를 권합니다.

## 자료는 이 PC 에 있습니다

- 등록한 PDF 원문, 검색 색인, 작업 기록은 모두 이 PC 의 `%APPDATA%\kr.school.docaid` 폴더에 저장됩니다. 프로그램을 지웠다 다시 깔아도 그대로입니다.
- **배포 전 검증** — 인터넷을 끊은(비행기 모드) 상태에서 앱 실행 · PDF 열기 · 낱말 검색 · 의미 검색 · 규정 해석 · 가정통신문 · 문자 · 작업 기록 · 과거 근거 원문 열기 · 기존 색인과 모델 사용을 실제로 수행했고, 모두 정상 동작했습니다. 그 28분 동안 프로그램·내장 브라우저(WebView2)·Ollama 가 이 PC 밖으로 연 네트워크 연결은 기록되지 않았습니다. 인터넷이 연결된 상태에서도 사용 중 밖으로 나간 연결은 사용자가 [업데이트 확인] 을 눌렀을 때의 GitHub 접속 한 번뿐이었습니다.
- 프로그램이 인터넷을 쓰도록 만든 곳은 두 가지이고, 둘 다 사용자가 버튼을 눌렀을 때만 동작합니다: [AI 모델 설치] 는 Ollama 에 모델 이름을 넘겨 모델 저장소에서 받게 하고, [업데이트 확인] 은 GitHub 의 업데이트 정보 파일을 읽습니다.

## 알려진 제한

- **Windows SmartScreen 경고** — 코드 서명 인증서가 없어 처음 실행할 때 "PC를 보호했습니다" 창이 뜰 수 있습니다. **추가 정보 → 실행** 을 누르세요. (업데이트 파일의 서명 검증은 이와 별개로 프로그램이 직접 합니다.)
- **스캔 PDF(이미지) OCR 미지원** — 글자가 없는 스캔 PDF 는 검색되지 않습니다.
- **자료 폴더 자체 암호화 없음** — 폴더 접근 권한은 Windows 계정 보호에 따릅니다.
- **복원 화면 없음** — 설정의 [지금 백업] 은 되지만 되돌리기는 프로그램을 끈 뒤 자료 폴더를 손으로 복사해야 합니다.
- **답변에 수분** — 로컬 AI 는 PC 성능을 따릅니다. GPU 가 없는 PC 에서 qwen3:8b 는 답 하나에 3~4분 걸립니다. 진행 표시에 이 PC 의 실측 시간을 보여 줍니다.
- HWP/HWPX 는 아직 읽지 못합니다. 한글에서 PDF 로 저장한 뒤 등록해 주세요.

## 설치

`DocAid_0.1.0_x64-setup.exe` 를 내려받아 실행합니다. 관리자 권한은 필요 없습니다. Windows 10/11 x64.

| 파일 | 무엇인가 |
|---|---|
| `DocAid_0.1.0_x64-setup.exe` | 설치 파일. 이것만 받으면 됩니다 |
| `DocAid_0.1.0_x64-setup.exe.sig` | 업데이트 서명. 프로그램이 업데이트할 때 확인합니다 |
| `latest.json` | 업데이트 정보. 프로그램이 읽습니다 |
| `SHA256SUMS.txt` | 내려받은 파일이 온전한지 확인용 |
