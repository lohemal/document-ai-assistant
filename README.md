# 업무자료 AI 도우미

학교 업무자료(매뉴얼·지침·공문)를 등록해 두고, 자연어로 물으면 **등록한 자료에서
근거를 찾아 답하고 그 근거가 된 파일과 쪽을 함께 보여 주는** Windows 프로그램입니다.

> 자료도, AI 실행도 **이 컴퓨터 안에서만** 이루어집니다.
> 업무자료를 외부 서버나 클라우드로 보내지 않습니다.

**개발 중입니다 (v0.1.0 · P0 뼈대 단계).** 설계와 진행 상황은
[`docs/01-설계안.md`](docs/01-설계안.md) 를 보세요.

---

## 무엇을 해 주나요

- **자료 검색** — "초3 지원금으로 교재비를 쓸 수 있어?" 처럼 물으면 등록한 자료에서
  근거를 찾아 답합니다.
- **근거 표시** — 답변마다 **어느 파일 몇 쪽**에서 나왔는지 보여 주고, 누르면
  그 PDF 의 그 자리에 형광펜이 칠해집니다.
- **모르면 모른다고 합니다** — 자료에서 근거를 찾지 못하면 지어내지 않고
  "등록된 자료에서 확인할 수 없습니다" 라고 답합니다.
- **자료집** — 늘봄학교, 초3 지원금처럼 묶어서 검색 범위를 좁힙니다.
- **문서 초안** — 같은 근거로 가정통신문·문자메시지 초안을 만듭니다.
- **작업 기록** — 언제 무엇을 물었고 어떤 근거로 답했는지 남습니다(기본 30일).

## AI 모델이 없어도 씁니다

이 프로그램은 AI 모델을 설치하지 않아도 실행되고, 아래 기능은 그대로 됩니다.

- 자료집 관리
- PDF 등록 · 텍스트 추출
- **원문 보기**
- **낱말로 찾기** (키워드 검색)

AI 모델은 프로그램 안에서 **[AI 모델 설치]** 를 눌렀을 때만 내려받습니다.
약 5GB 이고 최초 1회 인터넷 연결이 필요합니다. 설치하지 않아도, 설치에 실패해도
위 기능은 계속 쓸 수 있습니다.

## 설치

릴리스 페이지에서 `DocAid_0.1.0_x64-setup.exe` 처럼 생긴 설치 파일을 내려받아
실행하세요. 관리자 권한이 필요 없습니다.

> Windows가 "PC를 보호했습니다" 창을 띄우면 **추가 정보 → 실행** 을 누르세요.
> 코드 서명 인증서가 없는 프로그램은 모두 이렇게 나옵니다.

## 자료는 어디에 있나요

```
%APPDATA%\kr.school.docaid\
  data.db        검색 자료 · 작업 기록
  files\         등록한 PDF 사본
  backups\       자료구조가 바뀔 때 자동으로 만드는 백업
```

프로그램을 업데이트해도, 지웠다 다시 깔아도 이 폴더는 그대로 남습니다.

> ⚠ **이 폴더는 업무자료 그 자체입니다.** 개인정보가 담긴 자료를 등록했다면
> 이 폴더와 백업 파일에도 같은 주의가 필요합니다. 현재 버전은 자료를 암호화하지
> 않습니다.

## 만드는 방법 (개발)

### 필요한 것

- [Node.js](https://nodejs.org) 20 이상
- [Rust](https://rustup.rs)
- Visual Studio Build Tools (C++ 데스크톱 개발)

### 실행

```bash
npm install
npm run app
```

### 실제 자료를 건드리지 않고 연습하기

초기 설정을 처음부터 다시 해 보는 것처럼 **자료를 지우는 시험**을 할 때는
연습용으로 띄웁니다. identifier 가 달라 자료가 따로 저장됩니다.

```bash
npm run app:sandbox
```

### 검사

```bash
npm run check:model   # 배포 이름 · 버전 · 업데이터 설정
npm run build         # 타입 검사 + 화면 빌드
```

`check:model` 은 **배포가 조용히 깨지는 경우**를 먼저 막습니다 — 세 파일의 버전이
어긋나거나, 빌드 산출물 이름에 한글이 섞이거나, 업데이터 설정이 저장소와 어긋나는
경우입니다. 셋 다 빌드는 성공하고 릴리스 뒤에야 드러나는 사고입니다.

### 이름 규칙

**빌드·배포·파일 시스템에 닿는 이름은 전부 영문, 사용자에게 보이는 이름만 한글.**

| 자리 | 값 |
|---|---|
| `productName` · 설치 파일 | `DocAid` |
| identifier · 자료 폴더 | `kr.school.docaid` |
| 저장소 | `lohemal/document-ai-assistant` |
| 창 제목 · 화면 | 업무자료 AI 도우미 |

`npm run check:model` 이 이걸 검사합니다.

### 새 버전 내기

```bash
npm run version:set 0.2.0
npm run check:model
git add . && git commit -m "v0.2.0"
git tag v0.2.0 && git push origin main --tags
```

GitHub Actions 가 검사·빌드·서명·릴리스를 다 합니다.

> **업데이터 서명 키는 저장소 밖** `%USERPROFILE%\.docaid-release\` 에 둡니다.
> 잃어버리면 이미 설치된 프로그램에 업데이트를 보낼 수 없습니다.
